**Задание** Написать программу на языке C/C++ для перемножения двух квадратных матриц.
Исходные данные — файлы, содержащие значения матриц.
Выходные данные — файл с результатом умножения, время выполнения и объём задачи.
Обязательна автоматизированная проверка корректности результатов с использованием сторонних средств (например, Python с NumPy).

**Ход работы** Была разработана программа на языке C++ для перемножения двух квадратных матриц. В программе реализованы функции генерации исходных матриц, их чтения из файлов, а также запись результата умножения в файл.
Для проведения экспериментов была реализована автоматизация: в цикле выполнялись тесты для различных размеров матриц, а время выполнения операции перемножения измерялось с помощью библиотеки chrono. Результаты экспериментов записывались в отдельный файл для последующей обработки.
Для автоматической генерации входных данных использовалась отдельная программа, которая создает матрицы заданного размера и сохраняет их в файлы.
Корректность вычислений была проверена с использованием Python и библиотеки NumPy, путем сравнения результатов умножения, полученных в C++ и в Python.
Для наглядного анализа была построена графическая зависимость времени выполнения умножения матриц от их размера. График построен на основе полученных экспериментальных данных и демонстрирует рост времени выполнения с увеличением размерности матриц, что подтверждает теоретическую оценку сложности алгоритма.

**Вывод** В ходе работы была реализована программа для перемножения квадратных матриц и проведены эксперименты по измерению времени выполнения в зависимости от размера матрицы.
По результатам экспериментов установлено, что время выполнения алгоритма растет пропорционально кубу размера матрицы (O(N³)). Полученные результаты корректны и подтверждены автоматической проверкой с использованием сторонних средств.
