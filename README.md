## Задание
Модифицировать программу из л/р №1 для параллельной работы по технологии CUDA. Провести эксперименты с разными размерами матриц и различными конфигурациями сетки блоков.


------------------------------------------------------------------------

## Ход работы

Была модифицирована программа из лабораторной работы №1 для выполнения умножения квадратных матриц на GPU с использованием CUDA. Для вычислений было реализовано CUDA-ядро, в котором каждый поток рассчитывает один элемент результирующей матрицы. Ипользовалась видеокарта GeForce RTX 2060 Super 8GB GDDR6

Были проведены эксперименты для разных размеров матриц и нескольких конфигураций блоков: `8x8`, `16x16`, `32x8`, `8x32`, `32x16`. Время выполнения CUDA-ядра измерялось с помощью CUDA Events, результаты сохранялись в файл results_cuda.csv. По полученным данным были построены графики зависимости времени выполнения от размера матрицы и конфигурации блока.

## Вывод

В ходе работы была реализована CUDA-версия программы для перемножения квадратных матриц. Эксперименты показали, что использование GPU значительно ускоряет вычисления, особенно при больших размерах матриц.

Также было установлено, что выбор конфигурации блока влияет на время выполнения: на больших матрицах разные размеры блоков дают заметно отличающиеся результаты. Наиболее эффективными оказались конфигурации с большим количеством потоков в блоке.
