**Задание** Написать программу на языке C/C++ для перемножения двух квадратных матриц.
Исходные данные — файлы, содержащие значения матриц.
Выходные данные — файл с результатом умножения, время выполнения и объём задачи.
Обязательна автоматизированная проверка корректности результатов с использованием сторонних средств (например, Python с NumPy).

**Ход работы** Была разработана программа на языке C++, реализующая загрузку двух квадратных матриц из файлов, их перемножение, а также сохранение результата в файл.
Для измерения времени выполнения использовалась библиотека chrono. Также в программе вычисляется объём задачи как N^3, что позволяет оценить вычислительную сложность.
Корректность полученных результатов проверялась с помощью Python-скрипта, использующего библиотеку NumPy, где выполнялось аналогичное умножение матриц и сравнение результатов.
Программа поддерживает обработку матриц различных размеров и сохраняет результаты вычислений в файл.

**Вывод** В ходе работы была разработана программа для перемножения квадратных матриц на языке C++, реализована оценка времени выполнения и проведена автоматизированная проверка корректности результатов с использованием Python.
Установлено, что время выполнения алгоритма растёт кубически с увеличением размера матрицы, что соответствует теоретической сложности O(N^3)
